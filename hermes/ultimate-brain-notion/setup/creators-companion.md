# Creator's Companion 3.0: What's New

Creator's Companion 3.0, launched in November 2024, represents a complete redesign emphasizing simplicity and workflow speed for content creators using Notion.

## Key New Features

**Homepage Redesign**: The new dashboard provides quick access to active projects, ideas, and scheduled content. According to the documentation, "CC 3.0 immediately gives you quick access to your content ideas, in-progress projects, Channels, and more."

**Content Templates**: Built-in templates are included for videos, podcasts, live streams, newsletters, and blog posts. Each template prioritizes script/outline creation with supporting research and B-roll management tools.

**Course Planning**: The template now supports planning and launching online courses through a dedicated Course template within the Channels database.

**Workflow-Focused Views**: Three specialized pages help teams work more efficiently:
- Writer's Room (Research and Writing status projects)
- Film Queue (Recording status projects)
- Edit Bay (Editing status projects with kanban-style organization)

**New Databases**:
- **Wiki**: For documenting processes and SOPs
- **Swipes**: For collecting visual inspiration and reference materials
- **Centralized B-Roll**: Replaces individual project databases with one unified system

**Sponsor Management**: Enhanced Outreach Tracker and Calendar views for managing brand partnership pipelines.

## What Was Removed

The update eliminated Creator's Companion Lite, simplified the Idea validation system, and removed several underutilized properties in favor of streamlined alternatives.

## Upgrade Path

Direct upgrades aren't recommended. Instead, users should either start fresh with CC 3.0 or transfer data using the upcoming migration guide.

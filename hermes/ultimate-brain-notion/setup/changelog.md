# Ultimate Brain for Notion - Changelog Summary

This changelog documents updates to Ultimate Brain 3.0, a comprehensive Notion productivity template.

## Latest Updates (February 7, 2026)

The most recent release introduces several enhancements:

**Recurring Task Improvements**: A new "Enforce Schedule" feature allows recurring tasks to maintain their original schedule even when overdue. For example, "a daily recurring task overdue by 3 days will show a Next Due date that's 2 days in the past."

**Database Relations**: Users can now directly relate Tasks to Notes and Books to Notes, enabling better documentation linking and note organization within task and book pages.

**Enhanced Task Pages**: Tasks now feature tabbed layouts with dedicated sections for sub-tasks, recurring task history, and time-tracking sessions.

**Time Tracking Refinements**: Historical time-tracking sessions now associate correctly with their respective task instances in advanced recurring task setups.

## Previous Major Release (January 23, 2025)

This update introduced native time tracking, allowing users to "track how long your tasks take to complete, and even track multiple work sessions for each task."

Additional features included:
- Advanced recurring schedules (e.g., "the 3rd Thursday of each month")
- Daily planning properties (Energy, Location, Process/Immersive)
- Sub-task automations
- Native Notion Sub-Items integration

## Earlier Updates

- **December 2024**: Renamed the "Tags" property to "Labels" in the Tasks database for clarity
- **November 2024**: Public launch of Ultimate Brain 3.0

Each update includes detailed upgrade guides with video tutorials for implementation.
